# ADR-0002: Apache License 2.0 for UniPercept

- Status: Accepted
- Date: 2026-07-15
- Scope: UniPercept

## Decision

UniPercept is distributed under Apache-2.0. Its package dependencies retain
their own licenses and are not copied into this source repository.

The repository ships `LICENSE`, `NOTICE`, and `CONTRIBUTING.md`. Apache-2.0
includes an explicit patent grant, and contributions use the DCO.
